# Story 4.1: Git State Sync Tracker

Status: completed

## Story

As a Product Manager,
I want the system to automatically check-in generated specifications (e.g., `design-artifacts/`) to the local git branch,
so that artifact generation is perfectly synchronized with the codebase upon state save anchors.

## Acceptance Criteria

1. **Given** the user generates or updates specifications (e.g., in `design-artifacts/` or `docs/specs/planning-artifacts/`)
   **When** a state save anchor is triggered (e.g., when the `file_writer` tool successfully writes a file)
   **Then** the system automatically adds the file, commits the change to the local git branch, and pushes it to the remote git repository.
2. **Given** the auto-commit runs
   **When** creating the git commit signature
   **Then** the system MUST use the standard custom signature block `Agentic Foundry <agenticfoundry@google.com>` rather than relying on host-level `.gitconfig` attributes.
3. **Given** a workspace git sync is initiated
   **When** there are uncommitted changes in the worktree
   **Then** the system uses `go-git/go-git/v6` to cleanly commit and sync without invoking raw shell command overrides.
4. **Given** the agent initiates an explicit check-in or sync
   **When** the Git integration tool is run
   **Then** the tool executes parameterizable git add/commit/sync actions against the workspace.

## Dev Notes

- **Technology Stack**: Keep everything within Go 1.22+ and the established `github.com/go-git/go-git/v6` framework. Do NOT call shell or execute raw `git` CLI commands (e.g., using `os/exec`).
- **Signature Constraint**: Automated git signatures must match the values configured on the repository's `RepoConfiguration` dynamically retrieved:
  ```go
  &object.Signature{
      Name:  repoCfg.GitUserName,
      Email: repoCfg.GitUserEmail,
      When:  time.Now(),
  }
  ```
- **Workspace Location**: The local git clone lives at `{WorkspaceMountPath}/{userId}/{projectId}`.
- **OAuth Tokens**: Ensure authentication propagates the User's OAuth tokens via the state and `RepoConfiguration` dynamically generated by `core.NewRepoConfigFromState`.
- **State Anchors**: The write interceptor in `ai/plugins/bmad_interceptor.go` acts as the primary automated state anchor hook. Make sure it is cleanly integrated.
