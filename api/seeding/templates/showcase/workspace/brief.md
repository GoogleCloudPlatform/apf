# Product Brief: Foundry Showcase (On-Demand Provisioning)

## 1. Executive Summary
The **Foundry Showcase** project is designed to accelerate onboarding for new users of the **Agentic Product Foundry (APF)**. It allows users to provision a fully-configured, highly realistic sample workspace on-demand. This enables them to experience the platform's collaboration, design, and planning features immediately without setting up repositories or database integrations.

## 2. Objectives & Success Metrics
- **Objective**: Deliver a frictionless onboarding experience for new users, reducing the time-to-first-interaction (TTFI) from minutes to under 10 seconds.
- **Success Metric**: 100% of new users are able to explore the workspace canvas, read pre-populated design documents, and interact with the AI assistant immediately on a fresh install.
- **Success Metric**: Zero-configuration execution—no external database or VCS connections needed for the showcase.

## 3. Scope & Target Audience
- **Target Audience**: New users, product managers, designers, and engineering leads evaluating the Agentic Product Foundry.
- **In-Scope**:
  - A settings card in the "Project Templates" tab.
  - Deterministic database and filesystem seeding engine.
  - A secure, clean reset capability with path traversal guards.
- **Out-of-Scope**:
  - External repository syncing or production code deployments for the showcase project.
